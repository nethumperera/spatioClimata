# Changelog

## 0.1.0 - 2026-04-12

- Initial package structure and installable distribution.
- Added dataset catalog and request validation for ERA5 and GloFAS.
- Added authentication onboarding with optional browser redirection.
- Added resilient retrieval pipeline with retries and monthly/yearly outputs.
- Added optional Dask chunk support.
- Added CLI for auth, dataset discovery, and fetch jobs.
- Added tests, examples, CI workflow, and repository docs.
