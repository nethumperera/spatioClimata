Daily ERA5 for a Basin

Use native daily statistics for smaller transfer volume and fast downstream analysis.

from spatioclimata import FetchRequest, TimeRange, AreaBBox, fetch request = FetchRequest( dataset="derived-era5-single-levels-daily-statistics", variables=["total_precipitation", "2m_temperature"], time_range=TimeRange.from_strings("2020-01-01", "2020-12-31"), area=AreaBBox.from_sequence([6.22,80.41,5.91,80.64]), frequency="daily", ) result = fetch(request)

Hourly to Daily Conversion

Ask for daily output from hourly-native datasets and let the pipeline handle resampling.

request = FetchRequest( dataset="reanalysis-era5-single-levels", variables=["surface_runoff", "sub_surface_runoff"], ..., frequency="daily", merge_strategy="yearly", )

Dask-Chunked Processing

Use chunking to process larger jobs without loading everything into memory.

request = FetchRequest( ..., use_dask=True, chunks={"time": 240, "latitude": 16, "longitude": 16}, )
