Documentation

Get started quickly and scale safely with scientific rigor

The package is organized for both interactive analysis and repeatable production pipelines.

Install

pip install spatioClimata

Authentication

Run interactive setup and optionally open account/key pages in your browser.

spatioclimata auth init --open-browser

Discover Datasets

spatioclimata datasets list spatioclimata datasets variables reanalysis-era5-single-levels

Need a visual lookup? Use the Dataset Registry page to search supported datasets, variable descriptions, and support level.

Run a Pipeline

spatioclimata fetch \ --dataset cems-glofas-historical \ --variables river_discharge_in_the_last_24_hours \ --start 2021-01-01 \ --end 2021-12-31 \ --area 6.22,80.41,5.91,80.64 \ --frequency daily \ --merge-strategy yearly

Python API Quickstart

Use the programmatic API for notebook workflows and automated pipelines.

from spatioclimata import AreaBBox, FetchRequest, TimeRange, fetch request = FetchRequest( dataset="reanalysis-era5-single-levels", variables=["2m_temperature", "total_precipitation"], time_range=TimeRange.from_strings("2020-01-01", "2020-01-31"), area=AreaBBox.from_sequence([30.2, -95.9, 29.3, -94.9]), frequency="daily", output_dir="./outputs", ) result = fetch(request) print(result.saved_files)

Bounding Box and Grid

Use the order north,west,south,east. Keep the box large enough to include at least one grid cell.

--area 30.2,-95.9,29.3,-94.9 --grid 0.25,0.25

Use --grid to control resolution or avoid very small boxes that clip all grid points.

Validation Checklist

  • Confirm dataset ID and variable list before long requests.
  • Check time range coverage and expected timestep count.
  • Validate that bbox order is north,west,south,east.
  • Ensure target frequency is supported or convertible.

Outputs and File Naming

Outputs are stored as NetCDF with monthly or yearly grouping depending on merge strategy.

reanalysis_era5_single_levels_raw_hourly_2020_01.nc reanalysis_era5_single_levels_daily_2020_01.nc derived_era5_single_levels_daily_statistics_daily_2020.nc

Example Test Download

Small download for a quick sanity check (Houston area, 2 days).

spatioclimata fetch \ --dataset reanalysis-era5-single-levels \ --variables 2m_temperature,total_precipitation \ --start 2020-01-01 \ --end 2020-01-02 \ --area 30.2,-95.9,29.3,-94.9 \ --frequency daily \ --output-dir ./outputs-test

Use Dask for Larger Jobs

Enable Dask mode with chunk maps for large-scale temporal and spatial processing.

spatioclimata fetch ... --use-dask --chunks time=240,latitude=16,longitude=16

Scientific Notes

Aggregation logic

Prefer native daily products when available. Otherwise use hourly source and aggregate with time-aware mean/sum according to variable semantics.

Daily sum from hourly accumulated values:

\[ X_{d}=\sum_{h=1}^{24}x_{d,h} \]
Spatial integrity

Keep bounding boxes tight for lower transfer volume. Validate coordinate ordering and standardize to time/latitude/longitude before merge operations.

Approximate area of a bbox (km$^2$):

\[ A\approx |\Delta lat|\cdot 111.32\cdot |\Delta lon|\cdot 111.32\cdot \cos(\varphi_{mean}) \]
Quality controls

Validate expected timesteps, monotonic time ordering, and variable presence before yearly merge.

Expected hourly timesteps for $D$ days:

\[ N=24\cdot D \]
Area-weighted mean

When averaging spatial grids, weight by latitude to account for cell area differences.

\[ \bar{x}_{A}=\frac{\sum_{i}x_{i}\cos(\varphi_{i})}{\sum_{i}\cos(\varphi_{i})} \]

Daily mean for evenly sampled hourly records:

\[ \bar{x}_{d}=\frac{1}{N_{d}}\sum_{h=1}^{N_{d}}x_{d,h} \]

For accumulated variables (for example precipitation), daily sum is usually preferred:

\[ X_{d}=\sum_{h=1}^{N_{d}}x_{d,h} \]
