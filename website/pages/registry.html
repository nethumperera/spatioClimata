What if my dataset is not listed?

spatioClimata can still be extended even if a dataset is not in the built-in registry. Follow this path:

  1. Confirm the dataset id and parameters from Copernicus catalogue links.
  2. Use CLI discovery commands to inspect currently registered datasets.
  3. Open a GitHub issue requesting support and include variable/frequency requirements.
  4. Optionally extend the catalog locally through a custom DatasetCatalog in Python.
spatioclimata datasets list spatioclimata datasets variables reanalysis-era5-single-levels # then open issue: https://github.com/nethumperera/spatioClimata/issues
